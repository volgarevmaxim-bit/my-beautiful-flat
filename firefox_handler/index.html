Firefox-обработчик для «Моей красивой квартиры»

Кнопка «Открыть на Циане» на графике цен и в блокноте сначала пробует открыть объявление в Firefox, а если это невозможно — в браузере по умолчанию. Для этого нужен разовый обработчик протокола myflat:. Установка не требует прав администратора.

  1. Скачайте все три файла в один и тот же каталог:
    open_in_firefox.bat open_in_firefox.vbs register_firefox_handler.bat
  2. Запустите register_firefox_handler.bat двойным кликом (если Windows спросит — разрешите запуск). Подтверждение придёт диалоговым окном, консоль не откроется.
  3. Проверьте: нажмите «Открыть на Циане» в карточке варианта на графике цен. Ссылка откроется в Firefox без каких-либо консольных окон.

Если Firefox не установлен — ссылка откроется в браузере по умолчанию. Не перемещайте и не удаляйте каталог с файлами после установки; если переместили — запустите register_firefox_handler.bat заново из нового места.

Если обработчик устанавливали раньше (до ноября 2026) — запустите register_firefox_handler.bat ещё раз: новая версия запускается через wscript и не мигает окном PowerShell.

Обработчик открывает только ссылки ЦИАН (https://…cian.ru/…), прочие адреса игнорирует. Пока обработчик не установлен, кнопка «Открыть на Циане» честно открывает браузер по умолчанию.
